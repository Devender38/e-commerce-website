# Simple E-Commerce Website

## Overview
A basic online shopping website where users can view products, add items to cart, and place orders.

## Features
- View products  
- Add to cart  
- Remove from cart  
- Checkout page   
- Search products  

## Technologies Used
- HTML  
- CSS  
- JavaScript  


## How to Run

1. Open browser at https://devender38.github.io/e-commerce-website/

## Conclusion
A simple project to learn web development and e-commerce basics.
